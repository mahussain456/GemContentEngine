The quality bar

Six rules every drop must actually clear.

Most AI tools fail by shipping average content faster. GEM's pipeline is wired to refuse the obvious filler — each agent's output is graded against the bar below before the next agent runs.

i.
One clear idea per post
If the post tries to say three things, it says nothing. Architect picks one angle and kills the rest.
ii.
A two-second hook
Curiosity, tension, or a contrarian frame in the first line. No "in today's video," no warm-up filler.
iii.
Specific examples, not generic advice
Real numbers, real workflows, real tools. Writer rejects its own draft when it goes vague.
iv.
Visuals that match the brand
Brand voice flows into every Midjourney, DALL-E, and FLUX prompt — no random AI art slop.
v.
A CTA tied to the business goal
Not "follow for more." Save, share, reply, comment, or click — picked per channel, per intent.
vi.
A human approval beat
Pipeline output is a draft, not a publish. You always read and edit before anything ships.

FAQ

Frequently asked questions about GEM Content Engine

Do I need to install anything?
No. GEM is a single HTML file — open it in any modern browser. The only optional install is Ollama, if you want to run AI locally for free. Otherwise, paste an OpenAI / Anthropic / OpenRouter key in Settings and you're running.
What's the cost per generation?
If you use Ollama locally: $0. If you use OpenAI's gpt-4o-mini: roughly $0.02–$0.05 per full content pipeline (six agents, ~30 LLM calls). Claude 3.5 Sonnet is ~$0.12. Compare to Jasper at $49/month even if you don't use it.
Is my data private?
In Ollama mode, your data never leaves your computer. In cloud mode, your prompts go to whichever provider you chose (OpenAI, Anthropic, OpenRouter) — same as if you used ChatGPT directly. GEM itself has no server. We never see your work.
Can I use it for client work?
Yes — Founder's Edition includes a commercial-use license. Use the output for your own clients, your own brand, or your own products. White-label rebranding is on the roadmap for higher tiers once GEM ships its team features.
How does Scout pull trends — and where does it fall short?
Scout pulls live signals from Reddit and HackerNews directly in your browser (CORS-friendly). Google Trends has stricter CORS, so by default Scout falls back to r/popular as a trending proxy — covers 95% of niches well. If you want unrestricted Google Trends data, run a one-line local proxy (documented in the User Manual). The point: you always know exactly what Scout is reading.
What's on the roadmap after I buy?
Founder's Edition buyers vote on what ships next. The bigger workflow modules in development: a daily auto-brief tailored to your niche, an approve/edit/regenerate/reject workflow with version history, direct publish to Buffer/Later/Meta, and a performance loop where yesterday's winners feed tomorrow's brief. Lifetime updates means every release lands at no extra cost.
What's the difference vs. ChatGPT alone?
ChatGPT is a generalist with a blank prompt. GEM is six specialist agents with locked schemas — Brand, Scout, Architect, Writer, Visual Director, Channel Adapter — each with its own system prompt, output validation, and downstream handoff. The result is a complete content drop in 90 seconds, not a Slack thread of follow-up prompts.
